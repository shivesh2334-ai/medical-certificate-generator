# Medical Certificate Generator

A professional web application for generating medical certificates, fitness certificates, sick leave certificates, and Form 1A (RTO) documents.

## Features

- **Four Certificate Types:**
  1. Medical Certificate (for general medical purposes)
  2. Fitness Certificate (for employment/job applications)
  3. Sick Leave Certificate (for employee documentation)
  4. Form 1A (for driving license medical certification)

- **Professional PDF Generation:**
  - Automatic stamp placement
  - Doctor's signature section
  - Professional formatting
  - Clinic header with details

- **User-Friendly Interface:**
  - Clean, modern design
  - Responsive layout
  - Form validation
  - Instant PDF preview and download
